MAGNUS — Lesson Experience Update

Добавляет демонстрационный экран занятия:
- визуальная область видеоплеера (без реального видео);
- вкладки «Урок», «Конспект», «Заметки»;
- поле для заметок;
- интерактивный контрольный вопрос с обратной связью;
- переход из страницы курса в занятие.

Всё остаётся в демо-режиме: видео, сохранение заметок и результатов на сервере не подключены.

Установка: распакуйте содержимое архива в D:\MAGNUS с заменой файлов.
Сохраните текущие папки tgcloud, .tgcloud, public, node_modules и tgcloud.jsonc.

Публикация:
npm run build
npx tgcloud push
