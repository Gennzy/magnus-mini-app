# PROD-002 — модель обучения MAGNUS

## Идентификация
- **ID:** `PROD-002`
- **Название:** Определить основную модель обучения: самостоятельная, когортная или смешанная
- **Статус:** [~] In progress
- **Владелец:** MAGNUS project workflow
- **Создано / обновлено:** 2026-11-11

## 1. Цель и ожидаемый результат
Выбрать модель обучения, по которой будут проектироваться учебная траектория, академические правила, AI-поддержка и дальнейшие функции университета. Результат — однозначное решение, сравнение альтернатив, описание пути студента, операционных ограничений и условий возможного расширения.

## 2. Контекст и текущее состояние
- PROD-001 зафиксировала аудиторию, ценность и честные границы MAGNUS.
- Основной продукт — Telegram Mini App; бот не является основным местом обучения.
- В `tgcloud/lib/academicCatalog.js` подключены три демонстрационные программы по шесть занятий.
- Каталог описывает последовательные занятия и формат «Самостоятельное обучение с проверкой практики».
- `studentData.js` проверяет зачисление, порядок прохождения и результаты на сервере; академический паспорт строится из серверных записей.
- AI-тьютор работает через серверный endpoint; часть практики оценивается автоматически по заданной рубрике. Человеческий преподавательский состав и когорты не реализованы.
- В текущем продукте нет действующего расписания групп, календаря потоков, механики групповых занятий и обязательной посещаемости.
- Предыдущая полная проверка PROD-001 прошла: CI run 42984319752, SHA `82f8373065f83c0af7eac2f491efbafc14f6166b`.

## 3. Границы

### IN — входит
- Сравнить самостоятельную, когортную и смешанную модели по понятным критериям.
- Утвердить базовую модель MAGNUS для текущего продукта.
- Определить общий путь студента и принципы индивидуального темпа.
- Зафиксировать роль AI-тьютора, практики и серверного учёта.
- Описать условия, при которых групповой компонент может быть добавлен позже.
- Согласовать продуктовые формулировки и ограничения.
- Исправить документационную передачу контекста и регрессионный тест активного WP.

### OUT — не входит
- Изменение UI, runtime, API, схемы БД, учебного каталога и контента.
- Реализация групп, календаря, расписания, посещаемости, чатов или живых занятий.
- Найм преподавателей/кураторов и обещание ручной проверки.
- Определение статусов студента, правил зачёта, порогов, пересдач, апелляций и подписочного доступа — это отдельные PROD-WP.
- Исследование спроса с заявлением о подтверждённых результатах.

## 4. Зависимости и блокеры

## 7. План тестирования

### Автоматические
- `npm run check:docs` — проверка обязательных документов и согласованности активного WP.
- `npm run test:docs` — позитивные и негативные тесты документационного checker.
- Полный workflow `MAGNUS visual smoke tests` — checker, негативные тесты, tutor coverage, payment invariants, backend syntax, production build, desktop/mobile Playwright smoke.

### Ручные
- Сверить описание модели с `academicCatalog.js`, `studentData.js`, `tutor.js`, ADR-0003…ADR-0005 и PRODUCT_POSITIONING.
- Проверить отсутствие заявлений о расписании, когортах, живых преподавателях и ручной проверке.
- Среда: GitHub source review; ручная проверка в Telegram не требуется, поскольку runtime не меняется.

### Негативные и граничные сценарии
- Не называть продукт смешанным, пока групповой слой не доступен.
- Не требовать посещаемость и общий календарь от самостоятельного студента.
- Не обещать человеческого преподавателя или экспертную проверку.
- Не менять пороги, попытки, правила оплаты и доступ в рамках этого WP.

- **Runtime-проверка:** не требуется; runtime не меняется.
- **Ручная проверка:** сверка GitHub Actions на итоговом SHA.

## 9. Риски и план отката
- **Риск:** самостоятельная модель может давать меньше социальной мотивации. Снижение риска — последовательный маршрут, ясный следующий шаг, практика, прогресс и проверка гипотез на пилоте.
- **Риск:** AI-обратная связь может быть ошибочной. Снижение риска — прозрачное описание AI-поддержки и отдельная методика качества в PROD-012.
- **Обратная совместимость:** изменения только документационные; ID программ, уроков, зачисления и записи студентов не меняются.
- **Откат:** восстановить предыдущие версии перечисленных документационных файлов и теста. Данные студентов не затрагиваются.
