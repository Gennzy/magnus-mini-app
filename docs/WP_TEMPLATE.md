- **ID:** `WP-000`
- **Название:** кратко и конкретно
- **Статус:** `[ ] Planned` / `[~] In progress` / `[!] Blocked` / `[x] Done`
- **Владелец:** MAGNUS project workflow
- **Создано / обновлено:** YYYY-MM-DD
