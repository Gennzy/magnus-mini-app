# ADR-0002: Telegram Serverless для backend и хранения данных

- **Статус:** Accepted
- **Дата фиксации:** 2026-11-11
- **Связанный WP:** GOV-006
- **Заменяет / заменён:** Нет

## Контекст
Backend MAGNUS развёртывается в среде Telegram Serverless, а данные приложения доступны через SDK этой среды. Отдельный постоянно работающий сервер в текущей конфигурации не используется.

## Решение
Размещать серверные endpoint-функции и доступ к базе данных в Telegram Serverless. Секреты и доверенные серверные операции не переносить в клиентский bundle.

## Рассмотренные альтернативы
- Самостоятельный backend на отдельном хостинге — потребовал бы отдельной инфраструктуры и сопровождения; сейчас не является используемым вариантом.
- Клиентское хранение критических академических данных — не обеспечивает серверный контроль прав и правил.

## Последствия
### Положительные
- Backend и Mini App развёртываются в рамках выбранной платформы.
- Серверные endpoint-функции могут проверять Telegram-контекст и бизнес-правила.

### Отрицательные / компромиссы
- Зависимость от доступности, API, лимитов и модели исполнения Telegram Serverless.
- Требуется проверять совместимость модулей с runtime платформы.

### Ограничения и риски
- CI-компиляция модулей не равна полноценной проверке живого runtime и БД.
- Возможности резервного копирования/восстановления требуют отдельного подтверждения.
